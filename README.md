Stationery

A multi-seller stationery e-commerce web application developed using Java Servlets, JDBC and Apache Tomcat.

Project Description

Stationery is a web-based e-commerce marketplace that allows customers to browse and purchase stationery products from different sellers. Sellers can manage their products, while customers can view products, add items to the cart and place orders.

Problem Statement

Traditional stationery shopping requires customers to visit physical stores and makes it difficult to compare products and prices from different sellers. This project provides a centralized online platform where customers can conveniently browse and purchase stationery products from multiple sellers.

Objectives

- Provide an online platform for purchasing stationery products.
- Allow multiple sellers to manage their products.
- Allow customers to browse and search for products.
- Provide shopping cart and order management features.
- Store and manage application data using a relational database.
- Provide a simple and user-friendly web interface.
